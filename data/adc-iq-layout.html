    ADC、IQ 与数据立方体¶

    本章回答什么¶

    原始 adc_data.bin 只是有符号 16-bit 字序列。只有在确认 I/Q、lane、sample、RX、TX、chirp 的顺序后，它才会成为有物理意义的雷达数据立方体。

    文件未触及 int16 饱和 lane/TDM 顺序待采集配置确认

    从四个 int16 重建两个复数¶

    教程假设每四个字依次为 [I0, I1, Q0, Q1]：

    \[ z_{2n}=s_{4n}+j s_{4n+2},\qquad z_{2n+1}=s_{4n+1}+j s_{4n+3}. \]

    def _matlab_interleave_iq(raw_int16: np.ndarray) -> np.ndarray:
    if raw_int16.size % 4 != 0:
        raise ValueError(
            "MATLAB I/Q conversion expects raw int16 length to be divisible by 4; "
            f"got {raw_int16.size}."
        )
    raw_float = raw_int16.astype(np.float32, copy=False)
    complex_stream = np.empty(raw_int16.size // 2, dtype=np.complex64)
    complex_stream[0::2] = raw_float[0::4] + 1j * raw_float[2::4]
    complex_stream[1::2] = raw_float[1::4] + 1j * raw_float[3::4]
    return complex_stream

    complex_stream = _matlab_interleave_iq(frame_raw_int16)

    def _parse_frame_tdm_candidate(frame_raw_int16, cfg):
    complex_stream = _matlab_interleave_iq(frame_raw_int16)
    phys = complex_stream.reshape(
        (cfg.chirps * cfg.tx, cfg.samples, cfg.rx)
    )
    frame_cube = np.empty(
        (cfg.samples, cfg.chirps, cfg.virtual_channels),
        dtype=np.complex64,
    )
    for chirp_idx in range(cfg.chirps):
        tx_group = phys[chirp_idx * cfg.tx:(chirp_idx + 1) * cfg.tx]
        frame_cube[:, chirp_idx, :] = tx_group.transpose(
            1, 0, 2
        ).reshape(cfg.samples, cfg.virtual_channels)
    return frame_cube

    假设线性流按 physical chirp → ADC sample → RX，TX 在相邻 physical chirps 间轮换。

    更符合连续性，但仍需 profile/标定

    如何把 layout 变成可证实结论¶

    1. 归档 mmWave Studio 的 ADC format、lane format、chirpCfg、frameCfg 与 TX 序列。
    2. 在 1 m、2.5 m、5 m 放单个角反射器，检查 peak 是否随距离线性移动。
    3. 比较 12 个通道的 fast-time 连续性、零 Doppler 与幅相稳定性。
    4. 只有标定通过后，才把 candidate 设为正式 processing mode。
