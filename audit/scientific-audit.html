    三个必须分开的命题¶

    图像看起来有峰 ≠ 检测到真实目标
    相位可以 unwrap ≠ 得到可信微位移

    证据层级¶

    命题 直接证据 状态
    文件有 100 帧 文件长度 / 每帧长度 已证实
    strict 复现 MATLAB shape 单帧及三次 FFT shape 教程复刻
    strict layout 可能错误 64-bin 周期峰、连续性差 强证据
    TDM candidate 更可信 连续性与综合分数更优 待标定
    bin 30 是稳定目标 幅值 1.076%、低相干 不支持
    当前角图给出物理角度 角输入 4 有效 + 4 零，无校准 不支持

    P0：会改变整条处理链的错误¶

    问题 代码证据 科研影响 首要动作
    strict layout 与连续性冲突 strict 1.3248 vs candidate 0.2559 三次 FFT 的物理轴可能都错 导入 profile/lane 配置并做已知距离标定
    Doppler 仅 4/12 通道 range_profile[:,:,:cfg.rx] angle 输入一半为零 对全部虚拟通道计算
    3TX 使用 Tc speed_resolution ... cfg.tc 速度尺度/范围错 3 倍 使用同 TX revisit 时间
    跨 frame gap 插值复 IQ np.interp 实/虚部 约 74% 合成样本、谱伪影 每帧相干点或非均匀采样方法

    P1：决定“能否定量解释”的缺口¶

    • 角 FFT index 未经 arcsin 与阵列流形标定。
    • 缺少 TDM moving-target phase compensation。
    • range bin 30 没有 SNR、相干度或目标关联选择依据。
    • 12 通道缺少幅相校准和物理位置表。
    • 图像幅值未按窗增益/FFT 长度归一化，且不是 dB 标度。

    P2：复现与实现细节¶

    • MATLAB IQ 循环漏掉每帧最后四个 int16。
    • MATLAB range 轴从第 1 bin 开始，存在一 bin 显示偏移。
    • metadata 缺少输入 hash、代码版本、生成时间和采集 profile。
    • processing_mode 与 layout score 没有真正控制主链。
