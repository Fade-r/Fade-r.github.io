    项目边界与学习路线¶

    先区分三层“项目”¶

    层次 内容 在本项目中的角色
    硬件与采集 IWR1443 + DCA1000 + 未归档完整 profile 产生 adc_data.bin
    教程基线 面向 IWR1843+DCA1000 的三份 MATLAB 提供 IQ reshape 与三维 FFT 种子
    Python 扩展 既往 AI 生成并面向自采数据扩展 多帧、候选布局、相位、频谱、绘图、NPZ

    来源不是教学核心

    PKUFlyingPig/cs-self-learning 是用户记忆中的北大学习资源背景；公开核验没有发现它是本地三份 MATLAB 的直接来源。直接代码上游是 StZhang-B/PKU-Millimeter-Wave-Radar-Tutorial。

    你最终应能回答的四个问题¶

    1. 一个 int16 索引如何变成某帧、某 TX/RX、某 chirp、某 ADC sample 的复数值？
    2. Range、Doppler、Angle FFT 分别沿数组哪一轴，为什么对应相应物理量？
    3. Tc、3Tc、帧周期和采样窗分别进入哪条尺度公式？
    4. 哪些证据足以支持目标距离、速度、角度和微位移的科研结论？

    两条并行路径¶

    [I/Q stream]
  → MATLAB column-major block reshape
  → range FFT
  → Doppler 仅写 VC0..3
  → angle 读取 VC0..7（后四个为零）

    价值是复现并理解教程代码；不能因为“与教程一致”就自动视为本次 IWR1443 采集的真值。

    capture profile / lane format
  → 已知距离目标验证 I/Q 与 TDM cube
  → 全通道 Doppler + TX 时序补偿
  → 阵列幅相校准 + 角轴映射
  → 检测/关联/bin 跟踪
  → 相干相位与不确定度报告

    每章阅读模板¶

    本 Wiki 的核心章节固定采用同一顺序：

    物理问题本章究竟估计什么量？
    公式与单位哪些近似成立，尺度如何计算？
    shape 与 axis输入输出各维的物理意义是什么？
    真实代码当前项目在哪里实现？
    实测证据现有图与 metadata 支持什么？
    科研边界还缺少什么配置或标定？

    证据标签¶

    • 数据已验证：由文件、shape、hash 或数值不变量直接支持。
    • 教程复刻：忠实重现上游算法，包括已知缺陷。
    • 当前实现有局限：代码确实执行，但物理解释受限制。
    • 待配置确认：有较强数据支持，仍缺采集配置或标定。
    • 当前证据不支持：不能据现有输出形成该科研结论。
