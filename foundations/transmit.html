    发射信号¶

    雷达的发射电路产生高频电信号，天线将它辐射为电磁波。讨论信号处理时，通常用随时间变化的电压波形表示这个信号。

    正弦信号¶

    频率不变的信号可以写成：

    s(t)=Acos⁡(2πft+ϕ0).
    • A 是幅度，决定波形的高低。
    • f 是频率，单位为 Hz，表示每秒振荡多少次。
    • ϕ0 是初始相位，决定波形从周期中的哪个位置开始。

    括号中的 2πft+ϕ0 称为相位，单位为弧度。相位增加 2π，波形完成一个周期。频率越高，相同时间内的周期数越多。

    频率与波长¶

    电磁波在空气中的传播速度近似为 c=3×108 m/s。一个周期内传播的距离是波长：

    λ=cf.

    77 GHz 表示每秒振荡 77×109 次，波长约为 3.9 mm。

    IWR1443 和 IWR1843 的 ADC 采集的是接收机处理后的低频信号。若直接记录 77 GHz 波形，就需要远高于这些芯片 ADC 能力的采样率。接收机先将回波与本机发射参考信号相乘，再滤去高频部分，留下反映两者频率差的拍频信号。拍频通常在 MHz 量级，距离信息仍保留在其中。回波与混频将推导它如何由距离决定。

    线性扫频¶

    FMCW 雷达在一次扫频内逐渐提高频率。频率以固定速率增加时，称为线性扫频：

    f(t)=f0+St,0≤t<Tr.

    f0 是起始频率，S 是扫频斜率，Tr 是扫频时长。频率增加的总量称为扫频带宽：

    B=STr.

    例如，从 77 GHz 开始，以 30 MHz/µs 的速率上升，持续 40 µs。频率共增加 30×40=1200 MHz，即 1.2 GHz，终点为 78.2 GHz。

    Python 示例¶

    import numpy as np

f0 = 77e9                  # Hz
slope = 30e12              # 30 MHz/us = 30e12 Hz/s
t = np.array([0, 10, 20, 30, 40]) * 1e-6
frequency = f0 + slope * t
print(frequency / 1e9)      # 以 GHz 显示

    MATLAB 示例¶

    f0 = 77e9;
slope = 30e12;
t = [0 10 20 30 40]*1e-6;
frequency = f0 + slope*t;
disp(frequency/1e9);

    结果：

    77.0  77.3  77.6  77.9  78.2

    1e9 表示 109，1e-6 表示 10−6。计算时统一用 Hz 和秒，显示时再换成 GHz 和 µs。

    扫频信号的相位¶

    相位每增加 2π，信号振荡一次，因此：

    dϕ(t)dt=2πf(t)=2π(f0+St).

    从 0 积分到 t，用 u 表示积分变量：

    ϕ(t)−ϕ0=2π∫0t(f0+Su)du=2π[f0u+Su22]0t=2π(f0t+St22).

    加回初始相位 ϕ0：

    ϕ(t)=ϕ0+2π(f0t+St22).

    所以发射波形为：

    stx(t)=Acos⁡[ϕ0+2π(f0t+St22)].

    频率表达式里的 St 积分后是 St2/2。若直接把 f0+St 填进 cos⁡(2πft)，相位就变成 2π(f0t+St2)；求导并除以 2π 会得到 f0+2St，斜率多了一倍。频率随时间变化时，要先积分得到相位，再写波形。

    连续发射多个 chirp¶

    一次扫频结束后，雷达按设定时序准备下一次发射。对于相同的连续 chirp，起点间隔为：

    Tc=Tr+Tidle.

    其中 Tidle 是空闲时间。若一次扫频 40 µs、空闲 60 µs，则每 100 µs 开始一次新扫频。多个发射天线轮流工作时，还需记录每个 chirp 由哪一路天线发射；这会影响后续测速。

    IWR1443 与 IWR1843 都通过配置决定起始频率、斜率、时长和发射顺序。这些数值是例题参数，不是芯片型号的固定参数。参数含义参见 TI chirp 配置说明。
