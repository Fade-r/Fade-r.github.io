    I/Q 与采样¶

    混频和滤波之后，接收机得到频率较低的模拟信号。ADC（模数转换器）定时测量它的电压，把连续波形转换成可以由程序处理的数值序列。

    I 和 Q¶

    混频后留下的相位

    回波与混频得到：

    ϕb(t)=2πfbt+ϕc,fb=2SRc.

    fb 是拍频，S 是扫频斜率，R 是距离；ϕc 汇集了对静止目标不随时间变化的相位项。

    只记录一个余弦分量，不能在单个时刻区分相反的相位：cos⁡ϕ=cos⁡(−ϕ)。正交接收机使用相差 90° 的两路参考信号进行混频，得到 I、Q 两个分量。

    沿用发射相位减回波相位的约定，并选取使 Q 为正弦的正交参考方向。将接收幅度、混频与滤波增益合并记为 A，可写为（这里的 A 是拍频幅度，不再是发射幅度）：

    I(t)=Acos⁡ϕb(t),Q(t)=Asin⁡ϕb(t).

    同一个接收通道在同一时刻输出 I、Q 两个电压值，分别记录余弦和正弦分量。利用欧拉公式 ejϕ=cos⁡ϕ+jsin⁡ϕ，可以把它们合成一个复数：

    z(t)=I(t)+jQ(t)=Aejϕb(t),j2=−1.

    在复平面中，I 是横坐标，Q 是纵坐标。点到原点的距离为幅度，连线与横轴的夹角为相位：

    A=I2+Q2,ϕb=atan2(Q,I).

    例如 I=1,Q=1，幅度为 2，相位为 45°。程序中的 abs 计算幅度，angle 计算相位。

    定时采样¶

    采样率 Fs 表示每秒记录多少个采样点，相邻点的间隔为 1/Fs。如果从 t=0 开始，采样时刻为：

    tn=nFs,n=0,1,…,Ns−1.

    把 tn=n/Fs 代入 z(t)=Aej(2πfbt+ϕc)：

    z[n]≡z(tn)=Aexp⁡[j(2πfbnFs+ϕc)].

    方括号表示离散编号。若 ADC 从扫频开始后的 ta 才采样，就用 tn=ta+n/Fs；对恒定拍频，多出的 2πfbta 可并入初相位。下面的短例取单位幅度、零初相位，得到：

    z[n]=exp⁡(j2πfbnFs).

    设 fb=1 MHz、Fs=8 MHz，则每个信号周期采 8 个点。相邻两点的相位差是 2π/8=π/4，即 45°。

    Python 示例¶

    import numpy as np

fs = 8e6
fb = 1e6
n = np.arange(8)                 # 0 到 7
t = n / fs
z = np.exp(1j * 2*np.pi*fb*t)
print(np.round(z.real, 3))
print(np.round(z.imag, 3))
print(np.round(np.abs(z), 3))

    MATLAB 示例¶

    fs = 8e6;
fb = 1e6;
n = 0:7;
t = n/fs;
z = exp(1j*2*pi*fb*t);
disp(round(real(z),3));
disp(round(imag(z),3));
disp(round(abs(z),3));

    I、Q 和幅度依次为：

    I:  1.000  0.707  0.000 -0.707 -1.000 -0.707  0.000  0.707
Q:  0.000  0.707  1.000  0.707  0.000 -0.707 -1.000 -0.707
A:  1.000  1.000  1.000  1.000  1.000  1.000  1.000  1.000

    1j 是代码中的虚数单位，np.exp 和 exp 计算指数。I、Q 随时间变化，但两者合成的幅度保持为 1。

    量化¶

    ADC 不能保存无限精细的电压值，而是将电压映射到有限数量的数字等级，这一步叫量化。以有符号 16 位存储为例，一个整数可表示 −32768～32767。

    采样决定“什么时候测”，量化决定“用多少等级表示测量值”。电压超出 ADC 输入范围时，输出会卡在最大或最小码值，称为饱和。多个不同电压被记成同一个数，原来的高低差别已经丢失，因此后续补零或 FFT 无法恢复它们。

    ADC 的量化位数和文件的存储位宽可能不同，例如较少位数的采样值也可以装在 16 位整数中。解析时须核对有效位数与符号扩展方式。整数表示 ADC 码值；换算成电压需要量程和增益，进一步换算成功率还需要阻抗及接收链标定。

    混叠¶

    离散采样不能区分相差整数倍采样率的复正弦频率。因为：

    ej2π(f+Fs)n/Fs=ej2πfn/Fsej2πn=ej2πfn/Fs.

    例如，8 MHz 采样时，1 MHz 和 9 MHz 的复正弦给出相同的采样序列。单看这些点，程序无法判断原来是哪一个频率。采样前的模拟滤波因此要压低有效频带之外的信号，减少它们混入测量频带的机会。

    复数采样常用 [−Fs/2,Fs/2) 作为频率显示区间。雷达的实际有效拍频范围还受模拟滤波器和采集模式限制，应按配置确定。

    IWR1443 与 IWR1843 都需要区分实数采样和复数采样模式。这里及后续示例使用复数 I/Q 数据。格式说明见 TI ADC 数据文档。
