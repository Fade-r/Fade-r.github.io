    复数、采样和 FFT：先补齐这三个概念¶

    这一章先不处理雷达文件。我们从八个能手算的数开始，弄清后面每一次 FFT 都在做什么。需要的数学只有三角函数、复数和求和。

    1. 为什么一个采样点要用两个数¶

    普通实数波形可以写成 \(A\cos\phi\)。但只知道余弦值，不能唯一确定相位：例如正、负两个相位可能有相同的余弦值。正交解调同时保留两个分量：

    \[ I=A\cos\phi,\qquad Q=A\sin\phi,\qquad z=I+jQ=Ae^{j\phi}. \]

    把 I 当横坐标、Q 当纵坐标，复数就是平面上的一个点。点离原点多远是幅度，连线转过的角是相位。例如 1+1j 的横、纵坐标相同，所以相位为 45°；根据勾股定理，幅度为 √2。这里的 Q 正负号采用数学约定。

    自己算一次¶

    Python：

    import numpy as np
z = 1 + 1j
print(np.abs(z), np.degrees(np.angle(z)))  # sqrt(2), 45 度

    MATLAB：

    z = 1 + 1j;
disp([abs(z), rad2deg(angle(z))]);         % sqrt(2), 45 度

    abs 和 angle 是从同一个复数取两种信息。过早执行 abs 会丢掉相位，后面就无法再靠它测速度、角度或微位移。

    2. 采样把连续时间变成编号¶

    以采样率 \(F_s\) 观察一个频率为 \(f\) 的复信号：

    \[ t_n=n/F_s,\qquad z[n]=A\exp(j2\pi f n/F_s). \]

    每多一个采样点，相位增加 \(2\pi f/F_s\)。频率不同，点在复平面上转动的速度就不同。后面沿轮次、沿天线做 FFT，也是利用这种有规律的相位变化。

    离散采样不能区分相差整数倍 \(F_s\) 的频率，因为多出来的相位总是 \(2\pi\) 的整数倍。这叫混叠。复数采样常把主频率区间写为 \([-F_s/2,F_s/2)\)；实际雷达允许的拍频范围还受模拟滤波和采集配置限制。

    3. FFT 为什么能找到频率¶

    DFT 的第 k 个输出是：

    \[ X[k]=\sum_{n=0}^{N-1}z[n]\exp(-j2\pi kn/N). \]

    可以把它理解为：先假定信号在 N 个点中恰好转了 k 圈，用反方向旋转把这 k 圈抵消，再把剩下的复数相加。如果猜对了，每个点都朝同一个方向，相加很大；如果猜错了，各点分散在圆上，会相互抵消。FFT 是快速计算这组求和的算法，并不是另一种频谱定义。

    八个点的例子¶

    令 \(z[n]=\exp(j2\pi\cdot2n/8)\)，即八个采样点对应两个完整周期。

    n 0 1 2 3 4 5 6 7
    z[n] 1 j −1 −j 1 j −1 −j
    乘上 k=2 的反向旋转后 1 1 1 1 1 1 1 1

    因此 \(X[2]=8\)，其余整数格理论上为零。由于浮点误差，程序可能输出约 \(10^{-15}\) 的小数，而不是严格的零。

    Python：

    n = np.arange(8)
x = np.exp(1j * 2 * np.pi * 2 * n / 8)
X = np.fft.fft(x)
print(np.round(np.abs(X), 6))  # [0, 0, 8, 0, 0, 0, 0, 0]
print(np.argmax(np.abs(X)))    # 2

    MATLAB：

    n = 0:7;
x = exp(1j*2*pi*2*n/8);
X = fft(x);
disp(round(abs(X), 6));
[~, idx] = max(abs(X));
k = idx - 1;                 % MATLAB 的第 3 个元素，对应零起始 bin 2

    4. bin、频率和 fftshift¶

    bin 是频谱的格编号。N 点 FFT 的频率间隔为 \(F_s/N\)。未移位的前半段依次表示零频率和正频率，后半段通常解释为负频率。fftshift 只重新排列输出，把零频率放在中间，不会重新计算频谱，也不会改变分辨能力。

    Python：

    fs = 1000.0
frequency = np.fft.fftshift(np.fft.fftfreq(8, d=1/fs))
spectrum = np.fft.fftshift(X)
# frequency: [-500, -375, -250, -125, 0, 125, 250, 375] Hz

    MATLAB：

    fs = 1000;
frequency = (-4:3)*fs/8;      % 这里 N=8 为偶数
spectrum = fftshift(X);

    频谱与横轴必须一起移位。否则曲线看起来正常，但读出的频率会错。

    5. 为什么要加窗，为什么补零不能增加信息¶

    FFT 只看到有限长度的数据。如果频率不正好落在某一格，例如 2.3 格，能量会分散到很多格，这叫频谱泄漏。加窗把序列两端压低，可以减弱远处旁瓣，但主峰会变宽；相近的两个目标可能更难分开。

    本项目用对称 Hamming 窗：

    \[ w[n]=0.54-0.46\cos\frac{2\pi n}{N-1}. \]

    Python 的 np.hamming(N) 和 MATLAB 表达式 0.54-0.46*cos(2*pi*(0:N-1)/(N-1)) 实现同一公式。若单个复正弦恰好位于 FFT 格上，峰值约为 \(A\sum w[n]\)；要比较幅度，应交代这种增益，而不能把未归一化 FFT 幅值直接当作物理功率。

    把 256 点补零到 1024 点，只是在同一段数据的频谱上取更密的点。曲线更细，不等于原来分不开的目标现在就能分开。需要同时区分频谱采样间隔和由观测时长、带宽、窗函数决定的分辨能力。

    2. 改成 2.3，峰不再只落在一个格上。分别加窗、不加窗、补零，观察峰宽和旁瓣。
