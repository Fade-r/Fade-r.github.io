    FFT 与频谱¶

    采样后的波形随时间变化，频谱则表示信号包含哪些频率，以及各频率分量有多强。雷达测距需要从采样序列中找到拍频，这可以用离散傅里叶变换完成。

    DFT 与 FFT¶

    从采样点到频率

    I/Q 与采样中的单频序列为：

    z[n]=Aej(2πfbn/Fs+ϕc).

    Fs 是采样率，fb 是待估计的拍频。下面用 x[n] 泛指待分析的序列：它可以是这个单频信号，也可以包含多个目标和噪声。

    长度为 N 的复数序列 x[n]，其离散傅里叶变换（DFT）为：

    X[k]=∑n=0N−1x[n]e−j2πkn/N,k=0,…,N−1.

    n 是输入采样点编号，k 是输出频率格编号。一个频率格也称为一个 bin。FFT 是快速计算 DFT 的算法，两者计算的是同一组频谱值。

    公式中的指数相当于一个反向旋转的参考信号。若输入在这 N 个点里恰好转了 k 圈，两者相乘后就不再旋转，各点相加会得到较大的结果。频率不匹配时，乘积仍在旋转，相加时会发生抵消。

    8 点示例¶

    取一个在 8 点内完成 2 个周期的信号：

    x[n]=ej2π⋅2n/8.

    这 8 个点依次为 1,j,−1,−j,1,j,−1,−j。计算 k=2 时：

    x[n]e−j2π⋅2n/8=1.

    8 个 1 相加，所以 X[2]=8。为什么其他整数格为零？把信号代入 DFT，并合并指数：

    X[k]=∑n=07ej2π(2−k)n/8.

    令 r=ej2π(2−k)/8，就得到等比数列 X[k]=1+r+⋯+r7。当 k≠2 时，r≠1，两边乘以 r 再相减：

    rX[k]=r+r2+⋯+r8,(1−r)X[k]=1−r8,X[k]=1−r81−r.

    整数 k 满足 r8=ej2π(2−k)=1，所以分子为零，得到 X[k]=0。k=2 时分母也为零，不能用这个分式，必须回到 8 个 1 的直接求和。

    这个推导也解释了频谱泄漏：频率不落在整数格时，r8 通常不等于 1，其他格的和就不再为零。

    Python¶

    import numpy as np

n = np.arange(8)
x = np.exp(1j * 2*np.pi*2*n/8)
X = np.fft.fft(x)
print(np.round(np.abs(X), 6))
print(np.argmax(np.abs(X)))

    MATLAB¶

    n = 0:7;
x = exp(1j*2*pi*2*n/8);
X = fft(x);
disp(round(abs(X),6));
[~, index] = max(abs(X));
k = index - 1;
disp(k);

    频谱幅度为 [0,0,8,0,0,0,0,0]，峰位编号为 2。MATLAB 的第 3 个元素对应从 0 编号的第 2 格。浮点运算可能留下非常接近零的小数。

    DFT 的矩阵形式¶

    每个频率格都是一次加权求和

    X[k]=∑n=0N−1e−j2πkn/N⏟第 k 格的权重x[n].

    把同一个 k 的权重排成一行，把不同 k 的行叠起来，就得到下面的 DFT 矩阵。

    把输入的每个采样点放进列向量，DFT 就是矩阵乘法 X=FNx。矩阵第 k 行、第 n 列是 e−j2πkn/N：每一行负责一个频率格，每一列对应一个输入采样点。

    以 4 点为例，e−j2π/4=−j，展开各次幂可得：

    [X[0]X[1]X[2]X[3]]=[11111−j−1j1−11−11j−1−j]⏟F4[x[0]x[1]x[2]x[3]].

    例如第二行乘以输入列向量，就是 X[1]=x[0]−jx[1]−x[2]+jx[3]。这里的乘法不是逐元素相乘：先将同一行和输入对应位置相乘，再把四个乘积相加。

    下面的图可以逐行选择频率格，查看每个乘积怎样相加。输入固定为 x=[1,j,−1,−j]T，因此第 1 格的结果是 4，其余格为 0。

    Python¶

    import numpy as np
n = np.arange(4)
k = n[:, None]
F = np.exp(-1j*2*np.pi*k*n/4)
x = np.array([1, 1j, -1, -1j])
print(np.round(F @ x, 6))
assert np.allclose(F @ x, np.fft.fft(x))

    MATLAB¶

    n = 0:3;
k = n.';
F = exp(-1j*2*pi*k*n/4);
x = [1; 1j; -1; -1j];
disp(round(F*x,6));
assert(max(abs(F*x-fft(x))) < 1e-12);

    两种语言都得到 [0,4,0,0]T，数值误差内与 FFT 相同。显式构造 DFT 矩阵适合理解公式；数据较大时使用 FFT，不需要保存这个 N×N 矩阵。

    频率轴¶

    设采样率为 Fs，相邻频率格之间的间隔为：

    Δf=FsN.

    例如 Fs=8 MHz、N=8，每格对应 1 MHz，第 2 格对应 2 MHz。

    对于复数信号，完整频谱包含正、负频率。以 8 点 FFT 为例：

    数组位置（从 0 编号） 0 1 2 3 4 5 6 7
    频率 / MHz 0 1 2 3 −4 −3 −2 −1

    为什么第 5 格写成 −3 MHz，而不是 5 MHz？采样的混叠关系表明，相差 Fs 的频率产生相同的采样点。此处 5−8=−3 MHz，两种写法等价；选用 [−Fs/2,Fs/2) 区间时，就把第 5 格记成 −3 MHz。fftshift 按这个区间重新排列频谱，把负频率移到左边，零频率放在中间。

    下面重新生成 8 点示例，避免沿用矩阵示例中的 4 点变量：

    fs = 8e6
x = np.exp(1j*2*np.pi*2*np.arange(8)/8)
X = np.fft.fft(x)
frequency = np.fft.fftshift(np.fft.fftfreq(8, d=1/fs))
shifted = np.fft.fftshift(X)
print(frequency / 1e6)

    fs = 8e6;
x = exp(1j*2*pi*2*(0:7)/8);
X = fft(x);
frequency = (-4:3)*fs/8;
shifted = fftshift(X);
disp(frequency/1e6);

    结果为 [-4,-3,-2,-1,0,1,2,3] MHz。频谱和频率轴要一起移位。

    加窗¶

    FFT 处理的是有限长度的数据。当信号频率不恰好落在某个频率格上时，频谱能量会分散到其他格，称为频谱泄漏。

    频谱峰附近的主要隆起称为主瓣，周围较低的起伏称为旁瓣。窗函数把序列两端的幅度压低，减轻记录首尾截断带来的突变，通常能降低远处的旁瓣，但会让主瓣变宽。对称 Hamming 窗为：

    w[n]=0.54−0.46cos⁡2πnN−1.

    Python 用 np.hamming(N) 生成；MATLAB 可以直接按公式计算，不需要额外工具箱：

    window = np.hamming(x.size)
X_windowed = np.fft.fft(x * window)

    N = numel(x);
x = x(:);
window = 0.54-0.46*cos(2*pi*(0:N-1)'/(N-1));
Xwindowed = fft(x.*window);

    MATLAB 示例先把 x 和窗都整理成列向量，确保逐点相乘；行向量乘列向量会被隐式扩展成矩阵。处理多维数组时，应让窗函数只沿需要加窗的维度变化。

    补零¶

    将 N 个采样点补零后计算 NFFT 点 FFT，会把频率格间隔变为 Fs/NFFT。例如 256 点补到 1024 点，频谱格点会密 4 倍。

    补入的零不包含新的观测。它让同一条频谱曲线有更多计算位置，却没有缩窄由原记录时长和窗函数决定的主瓣，因此不能把原来重叠的两个主瓣真正分开。补零主要用于更细致地显示或估计谱峰位置。

    函数说明：NumPy FFT、MATLAB fft。
