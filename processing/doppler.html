    多普勒（Doppler）FFT 与 3TX TDM 时序¶

    多普勒处理把同一 range bin 在多个重复 chirps 中的相位演化映射为径向速度；在 TDM-MIMO 中，必须使用同一 TX/虚拟通道的真实重访间隔。

    慢时间 FFT¶

    固定 range bin 后，对重复观测 (m) 做 FFT：

    \[ X_d[f,k,\ell,p]=\sum_{m=0}^{N_c-1}X_r[f,k,m,p]w_d[m]e^{-j2\pi\ell m/N_c}. \]
    \[ v=\frac{\lambda f_D}{2},\qquad \Delta v=\frac{\lambda}{2N_cT_{\mathrm{slow}}},\qquad |v|_{\max}=\frac{\lambda}{4T_{\mathrm{slow}}}. \]

    为什么 Tc 与 3Tc 差三倍¶

    在标准 3TX TDM 轮换中，虚拟通道 TX1-RX1 在 TX2、TX3 发射后才再次被观察：

    physical chirp:   0      1      2      3      4      5
TX:               1      2      3      1      2      3
TX1 revisit:      └──────── 3Tc ────────┘
    量 当前教程轴 Tc=160 µs 3TX 审计轴 3Tc=480 µs
    ΔfD 48.828 Hz 16.276 Hz
    Δv 0.09402 m/s 0.03134 m/s
    |v|max 6.017 m/s 2.006 m/s
    128-loop CPI 20.48 ms 61.44 ms

    speed_profile = np.zeros_like(range_profile, dtype=np.complex128)
    doppler_window = make_window(cfg.doppler_window, cfg.chirps).reshape(1, -1, 1)
    temp = range_profile[:, :, : cfg.rx] * doppler_window
    speed_profile[:, :, : cfg.rx] = np.fft.fftshift(

    return speed_profile

    def doppler_fft(range_cube, n_doppler=128):
    """range_cube: [frame, virtual, loop, range_bin]."""
    loops = range_cube.shape[2]
    w = np.hamming(loops)[None, None, :, None]
    return np.fft.fftshift(
        np.fft.fft(range_cube * w, n=n_doppler, axis=2),
        axes=2,
    )

    对所有虚拟通道计算，并把 slow-time 轴明确放在 axis=2。

    TDM 运动补偿¶

    不同 TX 在不同时间发射。移动目标在 TX 间积累额外 Doppler 相位；进入空间 FFT 前应按 TX 时刻补偿：

    \[ X_{\mathrm{comp}}(t)=X(t)\exp[-j2\pi f_DtT_c]. \]

    补偿符号、TX 顺序和具体 (t) 必须用本机配置与已知运动目标验证。

    现有 doppler_spectrum_rangebin030_vc00.png 不是标准单帧 Range–Doppler 图

    它来自跨 100 帧的固定 bin 复数序列，并经过跨 frame gap 插值；应在 慢时间与相位 中作为失败诊断理解，而不是用来验证本节速度尺度。
