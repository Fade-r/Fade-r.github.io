    速度测量¶

    距离 FFT 之后，固定一个距离格和一个通道，每次该通道重复观测时取出该格的复数值。目标运动会使这串复数的相位随时间变化，多普勒 FFT 用于估计这种变化的频率。

    距离 FFT 输出中保留了什么

    距离测量的输出记为 Xr[k,m,p]，三个下标分别是距离格、轮次和通道。固定目标格 k0 与通道 p0，得到：

    z[m]=Xr[k0,m,p0].

    这串复数就是本章的输入。一次 chirp 内的采样点 n 已经经过 FFT；现在考察的是不同轮次 m 之间的相位变化。

    这里测得的是径向速度：目标沿雷达与目标连线方向的速度分量，而不是任意方向的总速度。

    位移与相位¶

    从拍频相位中取出距离项

    混频推导给出 ϕb(t)=2πfbt+2π(f0τ−Sτ2/2)，其中 τ=2R/c。 载频对应的距离相位为 2πf0τ=4πf0R/c。用参考载频 fc 和波长 λ=c/fc 表示，即为 4πR/λ。

    本章采用常用的窄带、帧内小位移近似：主要跟踪这项随轮次的变化，暂不计运动对单次 chirp 拍频和距离格位置的影响。

    电磁波传播一个波长 λ，相位变化 2π。目标远离雷达 ΔR，往返路程增加 2ΔR，因此按本教程的解调约定：

    Δϕ=2π2ΔRλ=4πΔRλ.

    若径向速度 v 恒定，经过时间 t 后 ΔR=vt。这里的 t 从首次观测起累计，不再是每个 chirp 内重新计时的快时间：

    ϕ(t)=ϕ0+4πvλt=ϕ0+2πfDt.

    比较两式可得多普勒频率：

    fD=2vλ,v=λfD2.

    例如波长近似为 4 mm，目标每毫秒远离 0.5 mm。往返路程每毫秒增加 1 mm，即四分之一波长，相位每次增加 π/2。4 ms 转一圈，所以 fD=250 Hz，速度为 0.5 m/s。

    慢时间采样¶

    设同一通道的重复间隔为 Tslow，把 t=mTslow 代入上式，再用 z=Aejϕ 表示复数值：

    z[m]=Aej(ϕ0+2πfDmTslow).

    其中 A 是该距离格的幅度，ϕ0 是第一次慢时间观测的相位，已包含传播、反射等固定相位，不仅是发射信号的初相位。这与估计拍频的形式相同，只是采样间隔由 1/Fs 换成了 Tslow。

    Python 示例¶

    import numpy as np

wavelength = 3e8/77e9
tslow, nc, fd = 1e-3, 64, 125.0
m = np.arange(nc)
z = np.exp(1j*2*np.pi*fd*m*tslow)

D = np.fft.fftshift(np.fft.fft(z))
f_axis = np.fft.fftshift(np.fft.fftfreq(nc, d=tslow))
index = np.argmax(np.abs(D))
v = wavelength*f_axis[index]/2
print(f_axis[index], round(v, 3))

    MATLAB 示例¶

    wavelength = 3e8/77e9;
tslow = 1e-3; nc = 64; fd = 125;
m = 0:nc-1;
z = exp(1j*2*pi*fd*m*tslow);

D = fftshift(fft(z));
fAxis = (-nc/2:nc/2-1)/(nc*tslow);
[~, index] = max(abs(D));
v = wavelength*fAxis(index)/2;
disp([fAxis(index), round(v,3)]);

    结果为 125 Hz、约 0.244 m/s。代码使用 77 GHz 对应的波长，不使用前面心算时近似的 4 mm。

    速度轴与无模糊范围¶

    慢时间信号与测速换算

    z[m]=Aej(ϕ0+2πfDmTslow),v=λfD2.

    Nc 次观测组成一帧的慢时间序列。下面先用 DFT 估计 fD，再把频率格换算成速度。

    慢时间序列代入 DFT 后，初始相位与幅度可以提出求和号：

    D[ℓ]=∑m=0Nc−1Aej(ϕ0+2πfDmTslow)e−j2πℓm/Nc=Aejϕ0∑m=0Nc−1ej2πm(fDTslow−ℓ/Nc).

    当 fDTslow=ℓ/Nc 时，每项指数都为 1，得到峰值 NcAejϕ0。于是：

    fD,ℓ=ℓNcTslow,vℓ=λ2fD,ℓ=λℓ2NcTslow.

    移位后，对于偶数 Nc，有符号频率格编号 ℓ 从 −Nc/2 到 Nc/2−1。速度轴为：

    vℓ=λℓ2NcTslow.

    相邻速度格间隔为 λ/(2NcTslow)。无模糊范围也可以从相位增量理解。相邻观测间：

    Δϕ=2πfDTslow=4πvTslowλ.

    采样无法区分相差 2π 整数倍的相位增量。采用 [−π,π) 作为主值区间，把 Δϕ 代入并乘以正数 λ/(4πTslow)，得到：

    −λ4Tslow≤v<λ4Tslow.

    增加观测次数可以细化速度格；增加重复间隔也会细化速度格，但会缩小无模糊速度范围。

window = np.hamming(nc).reshape(1, nc, 1)
doppler_cube = np.fft.fftshift(
    np.fft.fft(range_cube * window, axis=1), axes=1)

window = reshape(0.54-0.46*cos(2*pi*(0:nc-1)/(nc-1)),1,[],1);

    TDM 发射间隔¶

    3 路 TX 轮流发射时，若相邻实际 chirp 间隔为 160 µs，则顺序为：

    时刻 / µs 0 160 320 480
    发射通道 TX1 TX2 TX3 TX1

    TX1 每 480 µs 才重复一次，因此 Tslow=480 µs。若误用 160 µs，同一个频谱峰会被换算成 3 倍速度。

    IWR1443 与 IWR1843 都按实际发射时序计算这个间隔。单 TX、双 TX 轮发、三 TX 轮发以及 BPM 编码不能混用同一个时间参数。TDM 对测角相位的影响见角度测量。

    若目标在观测期间明显跨越距离格，固定一格就不能持续取得同一个目标，需先做目标跟踪或距离迁移校正。运动也会改变单次扫频的拍频：在相同符号约定和一阶近似下，fb≈2SR/c+fD。若仍直接用静止目标公式换算：

    R^=cfb2S≈R+cfD2S.

    最后一项是速度造成的距离偏移，这就是距离—速度耦合。得到可靠的 fD 后，可先从拍频中减去它，再换算距离。本章短例忽略了这一小量，并假设一帧内速度近似恒定。
