    慢时间、相位与通道相干性¶

    相位到微位移的公式¶

    固定目标距离单元 (k_0) 的复回波为 (z(t))：

    \[ \phi(t)=\operatorname{unwrap}[\arg z(t)],\qquad \Delta R(t)=\frac{\lambda}{4\pi}[\phi(t)-\phi(t_0)]. \]

    本项目 (lambda/(4\pi)=0.30646\ \text{mm/rad})。公式成立还需要高 SNR、单一主导散射体、通道相干、无 range migration、相邻相位变化不过 (pi)，并正确保留采样时间。

    当前 bin 30 为什么不可信¶

    证据 数值 含义
    zero-based range bin 30 ≈ 5.8629 m 配置固定选择，不是检测结果
    相对全谱最大幅值 1.076% 处于低幅区域
    幅值百分位 6.64% 大部分 bins 都比它强
    通道非对角相干中位数 0.0388 通道间几乎不相干
    解缠位移范围 −40.1…+27.0 mm 更像低 SNR 随机相位解缠

    times = np.empty(total_frames * cfg.chirps)

    def _resample_complex_to_uniform(trace, time_axis, dt):
    uniform_time = np.arange(time_axis[0], time_axis[-1] + dt * 0.5, dt)
    real_uniform = np.interp(uniform_time, time_axis, trace.real)
    imag_uniform = np.interp(uniform_time, time_axis, trace.imag)
    return real_uniform + 1j * imag_uniform, uniform_time

    更稳妥的第一版微位移链¶

    每帧对目标 bin 的 chirps 做相干平均，只保留一个复数，并使用真实 80 ms 帧间隔：

    from scipy import signal

def frame_phase_displacement(range_cube, range_bin, vc, wavelength, frame_period):
    z = np.mean(range_cube[:, vc, :, range_bin], axis=1)
    phi = np.unwrap(np.angle(z))
    phi = signal.detrend(phi, type="linear")
    displacement_m = wavelength * phi / (4.0 * np.pi)
    time_s = np.arange(z.size) * frame_period
    return time_s, z, displacement_m

    推荐修正，尚未并入正式主链

    TDM candidate 的 bin 14（约 2.736 m）表现更稳定：VC0 帧幅 CV 0.187、复相干度 0.992、去趋势位移标准差 0.0384 mm。但 8 s / 100 点只有 0.125 Hz 分辨率，仍不能把小谱峰认定为呼吸。
