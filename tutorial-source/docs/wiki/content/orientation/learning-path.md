# 帧、通道与数组

一次 chirp 产生一组采样点；连续多个 chirp 可以组成一帧。程序必须保留采样点属于哪个 chirp、哪个接收通道，才能分别测量距离、速度和角度。

## 单通道数据

假设一个接收通道，每次 chirp 采 4 个点，连续采 2 次。数据可以排成一个 4 行、2 列的数组：

每个元素都是 [I/Q 采样](../foundations/sampling.md)得到的复数。记 $x_{n,m}=I_{n,m}+jQ_{n,m}$，$n$ 是一次 chirp 内的采样点编号，$m$ 是重复观测编号：

\[
\begin{bmatrix}
x_{0,0} & x_{0,1}\\
x_{1,0} & x_{1,1}\\
x_{2,0} & x_{2,1}\\
x_{3,0} & x_{3,1}
\end{bmatrix}.
\]

行编号表示一次 chirp 内的采样时刻，列编号表示第几次 chirp。同一列的数据用于距离分析；距离 FFT 之后，同一距离格沿各列的数据用于速度分析。

一次 chirp 内的采样时间常称为**快时间**，同一通道重复观测的时间常称为**慢时间**。它们的采样间隔不同：前者由 ADC 采样率决定，后者由发射时序决定。

## 多个接收通道

增加接收通道后，用第三个维度存放通道编号：

```text
x[采样点, 重复次数, 通道]
```

例如 `x` 的尺寸为 `(256,64,4)`，表示每次 256 点、重复 64 次、4 个接收通道。数组尺寸在 Python 中称为 `shape`，MATLAB 用 `size` 查询。

### Python 示例

```python
import numpy as np

x = np.zeros((256, 64, 4), dtype=complex)
one_chirp = x[:, 0, 0]
one_channel = x[:, :, 0]
print(x.shape)
print(one_chirp.shape)
print(one_channel.shape)
```

结果分别为 `(256, 64, 4)`、`(256,)` 和 `(256, 64)`。

### MATLAB 示例

```matlab
x = complex(zeros(256,64,4));
oneChirp = x(:,1,1);
oneChannel = x(:,:,1);
disp(size(x));
disp(size(oneChirp));
disp(size(oneChannel));
```

结果分别为 `256 64 4`、`256 1` 和 `256 64`。Python 从 0 编号，MATLAB 从 1 编号；冒号都表示取出该维的全部元素。

## 多路发射与虚拟通道

若 3 路 TX 轮流发射，每次由 4 路 RX 接收，就有 $3\times4=12$ 种发射—接收组合。每种组合称为一个**虚拟通道**。

一轮发射顺序可以是：

| 实际 chirp | 发射天线 | 接收天线 |
| --- | --- | --- |
| 1 | TX1 | RX1～RX4 |
| 2 | TX2 | RX1～RX4 |
| 3 | TX3 | RX1～RX4 |

重复 64 轮，共发射 192 次 chirp，每个虚拟通道仍只有 64 次观测。按 `[采样点,轮次,虚拟通道]` 排列，数组尺寸为 `(256,64,12)`。

这 12 个虚拟通道分三次发射取得：同一次发射的 4 个 RX 同时接收，不同 TX 组之间存在时间差。因此，测速要使用同一 TX 的重复间隔；测角还要结合 TX/RX 的实际位置，并补偿移动目标在发射间隔内产生的相位变化。

## 数组轴与处理方向

| 运算 | 输入的一维序列 | Python | MATLAB |
| --- | --- | --- | --- |
| 距离 FFT | 同一 chirp、同一通道的采样点 | `axis=0` | 第 1 维 |
| 多普勒 FFT | 同一距离格、同一通道的重复观测 | `axis=1` | 第 2 维 |
| 空间 FFT | 同一距离—速度格的有序阵列通道 | `axis=2` | 第 3 维 |

这个表采用本教程的维度顺序。改变数组排列时，FFT 使用的轴也必须随之改变。空间 FFT 还要求输入通道构成合适的均匀阵列。

IWR1443 与 IWR1843 的最大 TX/RX 数相同，但实际启用通道、轮发次序和虚拟阵列位置由采集配置及板卡布局决定。
