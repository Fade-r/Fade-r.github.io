## 1. 先说清楚模拟了什么

使用项目的采样率、斜率、256 个采样点和 128 轮观测。阵列则明确简化为 **8 个已校准、间隔半波长的均匀线阵通道**，假定同时观测或已经补偿 TX 时间差。这不是 IWR1443 实际天线布局。

在窄带、远场、恒定径向速度、帧内距离迁移可忽略且忽略拍频中的多普勒偏移时，单目标模型写为：

\[
x[n,m,p]=A\exp\left\{j2\pi\left[
\frac{f_b}{F_s}n+f_DT_{\mathrm{slow}}m+
\frac{d\sin\theta}{\lambda}p\right]\right\}.
\]

三个相位项分别随采样点、轮次、通道编号变化，因此三次 FFT 分别沿这三个方向计算。练习把目标精确放在距离格 14、多普勒格 +5、180 点空间 FFT 的 +45 格，最后一个对应容易理解的 30°。

Python 生成代码：

```python
n = np.arange(256)[:, None, None]
m = np.arange(128)[None, :, None]
p = np.arange(8)[None, None, :]
cube = np.exp(1j*2*np.pi*(14*n/256 + 5*m/128 + 45*p/180))
```

MATLAB 生成代码：

```matlab
n = reshape(0:255,[],1,1);
m = reshape(0:127,1,[],1);
p = reshape(0:7,1,1,[]);
cube = exp(1j*2*pi*(14*n/256 + 5*m/128 + 45*p/180));
```

这是直接生成解调后的理想数组，不是完整的射频、混频器、ADC 和 DCA1000 仿真。I/Q 配对在文件开头用另一个小数组单独验证，不与这份模拟回波混淆。

## 2. 运行两份程序

Python：先进入 `radar-env`，再从项目根目录运行 `python docs/wiki/examples/tutorial_pipeline.py`。依赖只有 NumPy。

MATLAB：切换到项目根目录，执行：

```matlab
run('docs/wiki/examples/tutorial_pipeline.m')
```

MATLAB 版本需支持脚本内局部函数和隐式扩展（R2016b 及以上）。Hamming 窗在代码中直接按公式生成，不要求 Signal Processing Toolbox。

## 3. 每一步应该看到什么

| 步骤 | 正确答案或尺寸 | 它检查了什么 |
| --- | --- | --- |
| 小数组配 I/Q | `3+5j,4+6j,7+9j,8+10j` | I 和 Q 是否配对正确 |
| 八点 FFT | 零起始第 2 格幅度为 8 | FFT 和语言索引 |
| 生成单目标 | `(256,128,8)` | 三个轴的排列 |
| 距离 FFT | 第 14 格，2.736017 m | 采样点轴和米数换算 |
| 多普勒 FFT | 中心右侧第 5 格，0.156702 m/s | 轮次轴和 480 µs 间隔 |
| 空间 FFT | +45 格，30° | 通道轴和反正弦映射 |
| CFAR | 距离格 13、14、15 | 一个主瓣可能占多个检测格 |
| 独立微位移例子 | 逐点恢复已知正弦位移 | 相位解缠和 λ/(4π) |

2026-10-15 已在本机 `radar-env` 和 MATLAB R2026a 实际运行，两份程序均通过内置断言，输出一致。微位移设置的连续幅度为 0.1 mm；有限采样点上的最大绝对值约为 0.099803 mm，因为采样时刻没有恰好落在正弦峰顶。

## 4. 不只运行，要主动改坏一次

1. **只改速度横轴的间隔**：保持模拟数组不变，把 480 µs 改成 160 µs。速度变大三倍，说明横轴公式与 FFT 同样重要。
2. **交换两个数组维度**：然后仍沿原轴计算，观察为什么代码能执行却得到错误峰。先写 `shape/size`，再修正轴。
3. **把距离格 14 改成 14.4**：能量分散到相邻格。比较加窗和不加窗，再试补零；不要再要求峰值格恰好等于 14.4。
4. **只把角度 FFT 点数增大**：空间谱变细，但实际天线数没有增加。比较两个很接近的模拟方向能否真的分开。
5. **给复回波加噪声**：逐渐降低信噪比，观察峰位置和相位解缠何时失效。两种语言随机噪声不必逐点相同，比较统计误差即可。

前两项刻意破坏断言，应先预测会失败在哪里，再运行。不要为了让程序显示“通过”而直接删掉检查。

## 5. 怎样接回你的真实数据

先用[数据解析章](../data/adc-iq-layout.md)得到真实的单帧数组，核实配置与通道顺序，再替换模拟数组。距离与 Doppler 的窗口和 FFT 结构可以复用，但时间间隔必须来自采集配置。角度部分不能直接复用理想 8 元线阵假设，应先建立实际阵列坐标和校准表。

微位移部分从距离 FFT 的复数结果分支出来：选定稳定目标，保留真实时刻，判断帧内平均是否适用，再解缠。最后按[标定实验](../audit/validation-roadmap.md)与已知距离、速度、角度或位移逐项比较。

## 学会了没有，用这六个问题检查

1. 给定一个复数流编号，你能算出它应放进哪一帧、哪一轮、哪个通道、哪个采样点吗？
2. 不看范例，你能在两种语言中指定三次 FFT 的正确维度吗？
3. 你能从采样率、采样长度、斜率推导距离格间距，并解释有效带宽吗？
4. 你能根据 TX 发射顺序推导慢时间间隔，而不是直接使用 `Tc` 吗？
5. 你能解释角度 FFT 为什么需要阵元位置，以及为什么补零不是增加天线吗？
6. 你能指出一条相位位移曲线可信所需的信号与时间条件，并设计已知位移实验检验吗？

如果某项还不能回答，回到对应章节做小练习；如果都能回答，再读[项目代码导读](../code/code-map.md)，把简化实现与实际函数逐一对应。
